# lopsticles – Finanzrechner für die Beratung

Kostenlose Online-Rechner rund um **Altersvorsorge, Absicherung und Finanzierung in Deutschland**.
Entwickelt für Beratungsgespräche, frei nutzbar für alle: Alles wird im Browser gerechnet,
eine Anmeldung ist nicht nötig, und jede Rechengröße ist mit ihrer Rechtsgrundlage belegt.

### Warum offen?

Wer eine Pension, Rente oder Versorgungslücke berechnet, soll nachprüfen können, **wie** gerechnet wird.
Die Repositories enthalten den Rechenkern der Online-Rechner – dieselben Funktionen, ohne Oberfläche –
mit Fundstellen im Code und automatisierten Tests gegen die Normen.

Fehler gefunden oder neue Rechengrößen erschienen? Gern als Issue im jeweiligen Repository.
